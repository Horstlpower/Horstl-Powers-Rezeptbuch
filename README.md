# Horstl Powers Rezeptbuch

Ein persönliches Rezeptbuch als Web-App für iPhone, Android und PC – funktioniert offline,
die Rezepte bleiben auf dem eigenen Gerät.

## Funktionen
- Rezepte mit Foto, Zutaten, Zubereitungsschritten, Notizen und Quelle
- Kategorien, Suche (auch nach Zutaten) und Favoriten
- Portionen umrechnen
- Einkaufsliste – Rezept wählen, abhaken was zuhause ist, der Rest kommt auf die Liste
  (mit Datumsstempel)
- Rezepte teilen
- Eigenes Hintergrundfoto für die Startseite aus der Mediathek
- Export/Import als Datei – zum Sichern und Übertragen auf andere Geräte

## Installieren
- **iPhone:** Seite in Safari öffnen → „Teilen“ → „Zum Home-Bildschirm“
- **Android:** Seite in Chrome öffnen → ⋮ → „App installieren“
